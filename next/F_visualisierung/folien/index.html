Was fehlt in euren Daten?

Survivorship Bias heisst: Wir sehen nur die Fälle, die einen Filter überstanden haben.

Der Filter ist oft unsichtbar:

  • Bewertungen schreibt vor allem, wer sehr zufrieden oder sehr verärgert ist.
  • Von Start-ups hören wir meist die erfolgreichen.
  • Eine Umfrage per App erreicht nur Leute, die die App haben.

Vom Endpunkt zum Balken

Ein kurzer Code-Along in drei Schritten

Ein Diagramm braucht drei Dinge

im HTML: die Bibliothek und eine Zeichenfläche 

<script src="https://cdn.jsdelivr.net/npm/chart.js@4.5.1/dist/chart.umd.min.js"></script>
<canvas id="temperatur"></canvas>
im JavaScript: der Auftrag an Chart.js 

new Chart(document.querySelector('#temperatur'), {
  type: 'bar',                          // welcher Diagrammtyp
  data: { labels: [], datasets: [] },   // was gezeigt wird
  options: {},                          // wie es aussieht
});

Chart.js will zwei Listen

was die Wetter-API liefert 

"daily": {
  "time": ["2026-10-08", "2026-10-09", …],
  "temperature_2m_max": [14.9, 14.7, …]
}
was Chart.js will 

labels: ['2026-10-08', '2026-10-09', …]
data:   [14.9, 14.7, …]
die zwei Listen aus dem JSON holen 

const labels = json.daily.time;
const data = json.daily.temperature_2m_max;

Beide Listen sind gleich lang und stehen in derselben Reihenfolge.

Holen, umformen, zeichnen


async function zeichneTemperatur() {
  // 1 Holen
  const response = await fetch(ENDPUNKT);
  const json = await response.json();

  // 2 Umformen
  const labels = json.daily.time;
  const data = json.daily.temperature_2m_max;

  // 3 Zeichnen
  new Chart(document.querySelector('#temperatur'), {
    type: 'bar',
    data: {
      labels: labels,
      datasets: [{ label: 'Höchsttemperatur in Bern (°C)', data: data }],
    },
  });
}

Der Endpunkt muss andere Domains erlauben

Liegt die Grafik auf einer anderen Domain als der Endpunkt, blockiert der Browser die Antwort.

Eine Zeile im PHP-Endpunkt erlaubt den Zugriff:


header("Content-type: application/json");
header("Access-Control-Allow-Origin: *");

CORS heisst Cross-Origin Resource Sharing: Der Server sagt, wer seine Daten abholen darf.

Die Übergabe ist eine einzige Zeile

zuerst: Mock-Daten nach dem Datenvertrag 

const ENDPUNKT = 'data/mock.json';
sobald das Backend steht: der eigene Endpunkt 

const ENDPUNKT = 'https://eure-domain.ch/unload.php';

Funktioniert die Grafik danach unverändert, haben beide Teams den Datenvertrag eingehalten.
