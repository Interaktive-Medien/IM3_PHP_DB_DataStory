# Code-Alongs

Code-Alongs werden gemeinsam mit dem Dozierenden oder LBA entwickelt. Der Startcode
liegt direkt im jeweiligen Ordner, die fertige Fassung in `solution/`.

**Womit ihr die Seiten öffnet:** Bis und mit Transform über `php -S localhost:8000`
im Ordner des Code-Alongs, nie über das Browser-Symbol von PhpStorm – in der
Adressleiste muss `8000` stehen, nicht `63342`. Ab dem Load-Block liegen die Code-Alongs auf dem Webserver: PhpStorm
lädt jede gespeicherte Datei per FTP hoch, und ihr öffnet sie über eure Domain,
zum Beispiel `https://eure-domain.ch/code-alongs/D_load/11_datenbank_testen/`.
