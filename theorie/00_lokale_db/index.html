Wofür das gut ist

Ab jetzt braucht ihr eine Datenbank.

  • Sie läuft auf eurem Rechner, genau wie PHP bisher
  • MAMP bringt sie mit, dazu phpMyAdmin im Browser
  • Ihr könnt ausprobieren, ohne etwas kaputtzumachen

Am Schluss zieht alles auf einen Webserver um.

  • Dort gibt es dieselbe Oberfläche mit anderen Zugangsdaten
  • Umziehen heisst: vier Werte in config.php ändern
  • Genau dafür stehen sie in einer eigenen Datei

Ohne Datenbank geht es in diesem Block nicht weiter.

Plant die 45 Minuten ein, bevor ihr mit dem Laden anfangt.

Was am Ende stehen soll

  • Auf eurem Rechner läuft eine MySQL-Datenbank
  • Ihr könnt phpMyAdmin im Browser öffnen
  • Ihr kennt Host, Port, Benutzername und Passwort
  • Eure config.php verbindet sich damit

Dieselben vier Angaben braucht ihr später beim Deployment – nur mit anderen Werten.

Der Auftrag zum Kopieren

Ich brauche auf diesem Rechner eine lokale MySQL-Datenbank für ein PHP-Schulprojekt. - Installiere MAMP und starte die Server. - Sag mir danach Host, Port, Benutzername und Passwort. - Sag mir die Adresse, unter der ich phpMyAdmin öffne. - Erkläre mir jeden Schritt, bevor du ihn ausführst. Mein Betriebssystem ist macOS.

Die letzte Zeile anpassen, wenn ihr Windows benutzt.

Was ihr trotzdem selbst macht

  • phpMyAdmin wirklich im Browser öffnen und nicht nur der Zusage glauben
  • Die vier Werte notieren, statt sie später wieder zu suchen
  • Jeden Befehl kurz ansehen, bevor ihr ihn bestätigt

Zugangsdaten von einem Webhosting haben in keinem Chat etwas zu suchen.

Ein Agent, der nicht weiterkommt, erfindet manchmal einen Weg – dann lieber abbrechen und von Hand weitermachen.

Die config.php ausfüllen

config.php im Hauptordner – lokal mit MAMP 

$host     = '127.0.0.1';
$dbname   = 'im3_hitzesommer';
$username = 'root';
$password = 'root';

// DSN: die Adresse der Datenbank
$dsn = "mysql:host=$host;port=8889;dbname=$dbname;charset=utf8mb4";
  • Hier kommen die vier Werte hinein, die ihr notiert habt
  • Weicht ein Wert bei euch ab, gilt eurer und nicht der hier
  • Der Port 8889 gehört zu MAMP und steht deshalb im DSN
  • 127.0.0.1 statt localhost, sonst sucht PHP am falschen Ort

Die config.php gehört nicht ins Repository.

Von Hand

Wenn ihr keinen Agenten habt

MAMP installieren

  1. Auf mamp.info die kostenlose Version für euer System herunterladen
  2. Die Datei öffnen und der Installation folgen
  3. Das Programm MAMP starten, nicht MAMP PRO

MAMP bringt Apache, PHP und MySQL in einem Paket mit.

Wir brauchen daraus nur die Datenbank.

MAMP ist kostenlos. Die mitinstallierte PRO-Version ist kostenpflichtig und hier nicht nötig.

Server starten und Port ablesen

In MAMP auf Start klicken.

  • Die Anzeige für MySQL wird grün
  • Unter Einstellungen steht der Port
  • Diesen Port braucht ihr gleich
übliche Werte
AngabeWert
Host127.0.0.1
Port8889
Benutzerroot
Passwortroot

Auf Windows steht dort oft 3306 statt 8889.

Deshalb den Wert ablesen und nicht abschreiben.

phpMyAdmin öffnen

  1. In MAMP auf WebStart klicken – die Startseite öffnet sich im Browser
  2. Dort im Menü Tools auf phpMyAdmin gehen
oder direkt im Browser
http://localhost:8888/phpMyAdmin/

Dieselbe Oberfläche findet ihr später beim Webhosting wieder.

Datenbank anlegen

  1. In phpMyAdmin links auf Neu klicken
  2. Einen Namen eingeben, zum Beispiel im3_hitzesommer
  3. Als Kollation utf8mb4_general_ci wählen
  4. Auf Anlegen klicken

Die Datenbank ist jetzt leer – die Tabellen kommen im Unterricht dazu.

Die config.php ausfüllen

config.php im Hauptordner – lokal mit MAMP 

$host     = '127.0.0.1';
$dbname   = 'im3_hitzesommer';
$username = 'root';
$password = 'root';

// DSN: die Adresse der Datenbank
$dsn = "mysql:host=$host;port=8889;dbname=$dbname;charset=utf8mb4";
  • $dbname ist der Name, den ihr gerade angelegt habt
  • Benutzer und Passwort sind lokal beide root
  • Der Port 8889 gehört zu MAMP und steht deshalb im DSN
  • 127.0.0.1 statt localhost, sonst sucht PHP am falschen Ort

Die config.php gehört nicht ins Repository.

PHP startet ihr weiterhin selbst


php -S localhost:8000
  • MAMP liefert uns die Datenbank, nicht den Webserver
  • Eure PHP-Dateien bleiben in eurem Projektordner liegen
  • Im Browser ruft ihr sie über localhost:8000 auf

So ändert sich an eurer Arbeitsweise aus den letzten Tagen nichts.

Wenn es nicht läuft

Meldung oder Symptom Ursache
No such file or directoryIm DSN steht localhost statt 127.0.0.1
Connection refusedMAMP läuft nicht oder der Port stimmt nicht
Access deniedBenutzer oder Passwort falsch, lokal beides root
Unknown databaseDer Name in config.php passt nicht zur angelegten Datenbank
Seite lädt ewigIhr habt den Webserver-Port 8888 im DSN statt 8889
phpMyAdmin nicht erreichbarIn MAMP wurde nicht auf Start geklickt
