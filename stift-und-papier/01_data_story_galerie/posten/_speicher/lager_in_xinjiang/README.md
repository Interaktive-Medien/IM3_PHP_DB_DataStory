# Reserveposten B – Lager in Xinjiang

**Story:** [Reuters Investigates, «Tracking China's Muslim Gulag»](https://www.reuters.com/investigates/special-report/muslims-camps-china/) · **Medium:** Scrollytelling mit Satellitenbildern

Erschienen 2018, zusammen mit Earthrise Media.

## Antworten für die Auswertung

| Frage | Antwort |
| ----- | ------- |
| Daten | Anlage, Aufnahmedatum, Koordinaten, bebaute Fläche |
| Quelle | mehrere hundert Satellitenaufnahmen, ausgewertet von Earthrise Media |
| Zeitraum | rund zwei Jahre, 39 Anlagen; die bebaute Fläche verdreifachte sich fast zwischen April 2017 und August 2018 |

## Wofür sich der Posten eignet

Zeigt, dass Daten nicht als Tabelle vom Himmel fallen: Hier wurden Bilder
erst zu Zahlen gemacht. Ernstes Thema, ideal als Gegengewicht zu den
verspielten Posten.

## Aufbau

Blatt an die Wand, Laptop mit geöffneter Seite.

**Achtung:** Reuters blockt automatisierte Zugriffe. Die Seite vor der
Lektion einmal von Hand öffnen und prüfen, ob sie im Kurs-WLAN lädt.
Der Screenshot stammt aus der Fassung im Internet Archive.
