# Reserveposten E – Ein Jahr, Stunde für Stunde

**Story:** [Instagram-Beitrag von @alsttr](https://www.instagram.com/p/DS67K8UkWH3/) · **Medium:** Bilderstrecke

## Aufbau

- `posten.html` ausgedruckt an die Wand.
- Ein Laptop oder Tablet, damit man durch die Bilderstrecke wischen kann.
  Der Beitrag ist ohne Login sichtbar, die Cookie-Meldung wegklicken.

## Antworten für die Auswertung

| Frage | Antwort |
| ----- | ------- |
| Daten | Datum, Stunde, Kategorie der Tätigkeit |
| Quelle | er selbst, von Hand in eine Tabelle eingetragen |
| Zeitraum | jede Stunde des Jahres 2025, rund 8760 Zeilen |

Der Posten nimmt die Angst vor grossen Datenquellen: Eine Tabelle mit drei
Spalten reicht für eine Geschichte, die 147 000 Menschen geliked haben.
