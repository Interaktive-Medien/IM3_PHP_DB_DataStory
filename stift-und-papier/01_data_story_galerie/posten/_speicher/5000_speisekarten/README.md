# Reserveposten D – 5000 Speisekarten

**Story:** [The Pudding, «5,000 Restaurant Menus, Years 1880-1920»](https://pudding.cool/2026/06/menu-collection/) · **Medium:** Scrollytelling

## Antworten für die Auswertung

| Frage | Antwort |
| ----- | ------- |
| Daten | Speisekarte, Jahr, Lokal, Gericht, Preis |
| Quelle | Buttolph Collection der New York Public Library, ein Archiv von über 25 000 Karten |
| Zeitraum | Karten von 1880 bis 1920, gezeigt werden 5000 davon |

Die Sammlung wurde grösstenteils von einer einzelnen Frau zusammengetragen.

## Wofür sich der Posten eignet

Das Beispiel für historische Datensätze: nichts wird laufend gesammelt, der
Bestand liegt fertig da. Genau die Variante, die wir im Projekt bevorzugen.

## Aufbau

Blatt an die Wand, Laptop mit geöffneter Seite.
