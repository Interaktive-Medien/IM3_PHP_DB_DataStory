# Reserveposten A – BahnMining

**Story:** [Vortrag von David Kriesel](https://youtu.be/0rb9CfOvojk) · **Medium:** Video

## Aufbau

- `posten.html` ausgedruckt an die Wand.
- Laptop mit dem Video und **zwei Kopfhörern**, sonst stört der Ton die
  anderen Posten.
- Ausschnitt vorbereiten: ab etwa Minute 17, dort kommen die Diagramme zu
  Verspätungen und Ausfällen.

## Antworten für die Auswertung

| Frage | Antwort |
| ----- | ------- |
| Daten | Zug, Halt, Sollzeit, Istzeit, Ausfall ja/nein |
| Quelle | Abfahrtstafeln der Deutschen Bahn, selbst abgefragt und gespeichert |
| Zeitraum | ein volles Jahr, rund 25 Millionen Halte, gut 50 000 pro Tag |

Das ist der Posten, der zeigt, was sich aus einer selbst gesammelten Tabelle
herausholen lässt.
