# 03 – Von JavaScript zu PHP

> **Ziel:** Die Studierenden holen die Programmierkonzepte aus IM2 zurück und
> finden sie in PHP-Code wieder, den sie noch nie gesehen haben. Botschaft am
> Schluss: Ihr habt programmieren gelernt, nicht JavaScript – die Konzepte
> bleiben, nur die Schreibweise ändert.

**Dauer:** 35' inklusive Besprechung · **Sozialform:** Einzelarbeit →
Partnerarbeit → Plenum

**Einsatz:** zu Beginn von Block A, direkt vor dem Code-Along
[00 Hallo PHP](../../code-alongs/A_PHP_Basics/00_hallo_php) und vor
[Theorie A](../../theorie/A_PHP_Basics).

## Warum diese Übung

Die Studierenden sollen in den nächsten Tagen PHP schreiben, ohne es je gesehen
zu haben. Das klingt nach viel – ist es aber nicht. In IM2 haben sie nicht
JavaScript gelernt, sondern programmieren: Variablen, Bedingungen, Listen,
Schleifen, Funktionen. Das gibt es in jeder Sprache, PHP schreibt es nur anders.

Die Übung macht sichtbar, wie viel davon schon da ist. Und sie zeigt allen, wo
es hakt, bevor die Theorie losgeht.

## Die Frage

```text
Was habt ihr in IM2 gelernt: JavaScript oder programmieren?
```

## Material

[`arbeitsblatt.html`](arbeitsblatt.html) im Browser öffnen, `Cmd+P`, A4 quer,
Hintergrundgrafiken an. **Die zwei Seiten auf zwei separate Blätter drucken**,
pro Person einen Satz. Dazu Stift und Whiteboard – kein Laptop, keine
Unterlagen, keine KI.

**Arbeitsblatt 2 erst nach Teil 1 austeilen.** Es steht der Lösung von
Arbeitsblatt 1 zu nahe; wer es vorher hat, schreibt ab statt zu erinnern.

[`loesung.html`](loesung.html) erst projizieren und danach ggf. als Handout
austeilen. Oder Studierende auf Download im Repo hinweisen.

## Verlauf

| #   | Schritt                                                                                                                                           | Dauer |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----: |
| 1   | **Rahmen:** Frage an die Wand – _Was habt ihr in IM2 gelernt: JavaScript oder programmieren?_ Nicht beantworten. Arbeitsblatt 1 austeilen.        |    5' |
| 2   | **Teil 1, allein:** sechs Aufgaben in JavaScript lösen, aus dem Kopf. Still, nicht helfen. Lücken sind erlaubt und werden angekreuzt.             |  7.5' |
| 3   | **Teil 2, zu zweit:** Arbeitsblatt 2 austeilen. Derselbe Code in PHP – pro Zeile notieren, was anders ist, Unklares mit `?` markieren.            |  7.5' |
| 4   | **Share:** Übersetzungstabelle `Konzept \| JavaScript \| PHP` am Whiteboard füllen, reihum eine Zeile pro Paar. Bei Uneinigkeit begründen lassen. |   10' |
| 5   | **Abschluss:** Frage von Schritt 1 beantworten lassen, dann die Lösung auflegen.                                                                  |    5' |

Es geht nicht um perfekte Syntax, ein Semikolon zu wenig ändert nichts. Lücken
sind kein Problem, sie sind die eigentliche Information auf dem Blatt.

## Was danach bleibt

Die Übersetzungstabelle JavaScript → PHP bleibt den ganzen Block A am
Whiteboard stehen und wächst mit jedem Code-Along.

Die Studierenden behalten ihre Blätter. Am Ende von Block A holen sie sie
nochmals hervor und streichen alle `?` durch, die dann beantwortet sind.
