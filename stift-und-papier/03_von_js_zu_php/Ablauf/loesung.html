Von JavaScript zu PHP – Lösung

Die Übersetzungstabelle
Ihr habt in IM2 programmieren gelernt, nicht JavaScript gelernt. Die Konzepte bleiben, die Schreibweise ändert.
# Konzept JavaScript (IM2) PHP (IM3) Merksatz
1 Variable 
let temperatureC = 19.4;
 
$temperatureC = 19.4;
 ≈ Kein let und kein const, dafür ein $ vor jedem Namen – immer, auch später beim Benutzen.
2 Ausgabe 
console.log(satz);
 
echo $satz;
 ≈ echo schreibt nicht in die Konsole, sondern in das, was der Server zurückschickt. Es ist die Antwort selbst.
2 Variable im Text 
`Aare in ${location}`
 
"Aare in $location"
 ≈ Doppelte Anführungszeichen sind PHPs Backticks. In einfachen ('…') passiert nichts.
2 Texte verbinden 
'Aare in ' + location
 
'Aare in ' . $location
 ≈ Punkt statt Plus. Das + ist in PHP ausschliesslich Rechnen.
3 Bedingung 
if (t >= 18) { … }
else if (…) { … }
 
if ($t >= 18) { … }
elseif (…) { … }
 ✓ Praktisch identisch. elseif wird zusammengeschrieben, sonst ändert nichts.
4 Array 
const t = [18.9, 19.4];
t[1]
 
$t = [18.9, 19.4];
$t[1]
 ✓ Eckige Klammern, Index ab 0. Genau wie in IM2.
4 Daten mit Namen 
const s = { Bern: 19.4 };
s.Bern
 
$s = ['Bern' => 19.4];
$s['Bern']
 ≈ PHP kennt kein Objekt mit Punkt. Es heisst assoziatives Array: eckige Klammern und =>.
5 Schleife 
t.forEach((wert) => {
  console.log(wert);
});
 
foreach ($t as $wert) {
    echo $wert;
}
 ≈ Gleiche Idee, kürzere Schreibweise: keine Pfeilfunktion, kein Callback. Das as vergibt den Namen für ein Element.
6 Funktion 
function f(ort, t) {
  return `${ort}: ${t}`;
}
 
function f($ort, $t) {
    return "$ort: $t";
}
 ✓ Dasselbe Wort, dieselbe Struktur, dasselbe return. Nur die $-Zeichen kommen dazu.

Kein einziges Konzept ist neu

Drei Zeilen sind praktisch identisch, sechs nur anders geschrieben. Neu zu lernen sind drei Schreibweisen: das $, der Punkt zum Verbinden und foreach. Der Rest ist IM2 mit anderer Kleidung.

Was wirklich neu ist – aber nicht heute

PHP läuft auf dem Server, nicht im Browser. Es gibt kein document, keine Events und kein onclick. Genau deshalb steht am Ende JSON und nicht eine Webseite.
