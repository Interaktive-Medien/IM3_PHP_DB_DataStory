Arbeitsblatt 2 · Teil 2: dasselbe in PHP

Zu zweit: Dieselben Aufgaben in PHP. Mit Arbeitsblatt 1 vergleichen und rechts notieren, was anders ist.

# PHP Was ist anders als in JavaScript?
1 
$temperatureC = 19.4;
2 
echo "Aare in $location: $temperatureC °C";
3 
if ($temperatureC >= 18) {
    echo "angenehm";
} else {
    echo "frisch";
}
4 
$temperatures = [18.9, 19.4, 20.1];
echo $temperatures[1];
5 
foreach ($temperatures as $temperature) {
    echo $temperature . " °C\n";
}
6 
function formatMeasurement($location, $temperatureC)
{
    return "Aare in $location: $temperatureC °C";
}
echo formatMeasurement('Bern', 19.4);
